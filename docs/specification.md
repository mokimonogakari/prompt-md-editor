# 仕様書 — Prompt MD Editor

## 機能一覧

| # | 機能名 | 説明 | ステータス |
|---|--------|------|-----------|
| 1 | マークダウン編集 | textareaベースのエディタ。Tabで2スペース挿入 | 済 |
| 2 | 記法ツールバー | 見出し/太字/斜体/取り消し線/コード/リスト/チェック/引用/コードブロック/表/リンク/区切り線/XMLタグの挿入 | 済 |
| 3 | ライブプレビュー | marked (GFM, breaks) で変換し DOMPurify でサニタイズして表示。入力から120msデバウンス | 済 |
| 4 | プロンプトテンプレート | 汎用/文章作成/要約・分析/コード生成/アイデア出し/翻訳 の6種を挿入。既存内容がある場合は置換or末尾追加を確認 | 済 |
| 5 | .md出力 | 編集内容をUTF-8の.mdファイルとしてダウンロード。ファイル名はドキュメント名（未入力時は `prompt-YYYYMMDD-HHmm.md`） | 済 |
| 6 | クリップボードコピー | マークダウン原文をコピー | 済 |
| 7 | 自動保存 | localStorage に本文とドキュメント名を保存（500msデバウンス）。再訪時に復元 | 済 |
| 8 | 表示切替 | 編集のみ / 分割 / プレビューのみ | 済 |
| 9 | 記法ヘルプ | チートシートとプロンプト作成のコツをサイドパネル表示 | 済 |
| 10 | ショートカット | Ctrl/Cmd+B 太字、Ctrl/Cmd+I 斜体、Ctrl/Cmd+S .mdダウンロード | 済 |
| 11 | 全消去 | 確認ダイアログ付きで本文クリア | 済 |

## 画面一覧

| 画面名 | パス | 説明 |
|--------|------|------|
| エディタ | / (index.html) | 単一画面。ヘッダー・ツールバー・編集/プレビュー2ペイン・ステータスバー・ヘルプパネル |

## API仕様

なし（外部通信を行わない完全クライアントサイドアプリ）。

## データモデル

localStorage のみ使用。

| キー | 型 | 内容 |
|------|----|------|
| `pme.content` | string | エディタ本文（マークダウン原文） |
| `pme.title` | string | ドキュメント名（出力ファイル名に使用） |

## 非機能要件

- **パフォーマンス**: プレビューは120msデバウンス。想定文書サイズ（〜100KB）で体感遅延なし
- **セキュリティ**: DOMPurifyによるサニタイズ、metaタグCSP、外部送信ゼロ、ライブラリ同梱によるバージョン固定
- **可用性**: GitHub Pages のSLAに準拠。ローカルへ.md出力できるためデータのポータビリティを確保
- **対応環境**: モダンブラウザ（Chrome / Edge / Safari / Firefox 最新）。720px以下はモバイルレイアウト
